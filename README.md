OOU GPA & CGPA Calculator

A responsive, beginner-friendly GPA and CGPA calculator and learning guide for Olabisi Onabanjo University (OOU) students.

Features

- GPA and CGPA explanations.
- OOU five-point grading scale.
- Interactive semester GPA calculator.
- Cumulative CGPA calculator.
- Automatic grade and quality-point calculations.
- Step-by-step worked examples.
- Academic success tips.
- Frequently asked questions.
- Mobile-friendly responsive design.
- Offline functionality.

GPA Formula

GPA = Total Quality Points ÷ Total Credit Units

Quality Points = Credit Units × Grade Point

CGPA Formula

CGPA = Total Cumulative Quality Points ÷ Total Cumulative Credit Units

The calculator uses weighted semester GPAs when calculating CGPA.

Getting Started

1. Clone or download this repository.
2. Open "index.html" in your browser.
3. Enter your course examination scores.
4. View your calculated GPA.
5. Enter semester GPAs and credit units to calculate your CGPA.

No installation or external libraries required.

Deployment

This project can be hosted using GitHub Pages.

1. Push the project to GitHub.
2. Go to Settings → Pages.
3. Select Deploy from a branch.
4. Select your main branch and root folder.
5. Save your settings.
